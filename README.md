# ghinwabousahyoun.github.io
Project Overview

The Smart Healthcare Appointment System is a web-based platform designed to simplify and digitalize the process of booking medical appointments. It allows patients to search for doctors by specialty, view availability, and book appointments, while doctors can manage schedules, view patients, and add diagnoses and prescriptions.

The system also integrates machine learning to support multi-symptom disease prediction, enhancing decision support in healthcare services.
This project was developed as a Senior Project for the Computer Science program.

Objectives

Facilitate easy and fast doctor appointment booking
Reduce manual scheduling and administrative workload
Provide patients with digital medical records
Assist doctors with availability management and prescriptions
Integrate AI for cancer-detection prediction

▶️ How to Run the Project
1️⃣ Backend (PHP)

Place the project inside htdocs
Import schema.sql into MySQL
Update database credentials in PHP config file
2️⃣ Flask API (Machine Learning)
pip install flask scikit-learn pandas numpy
python app.py

3️⃣ Frontend

Access via localhost using XAMPP
